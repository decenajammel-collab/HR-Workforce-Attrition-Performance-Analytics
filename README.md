# HR Workforce Attrition & Performance Analytics

## Project Overview
This project is an end-to-end data analytics solution built to analyze employee retention, departmental turnover, and workplace burnout factors. The goal is to provide corporate leadership with actionable insights and an interactive monitoring tool to reduce voluntary attrition.

## Tech Stack
* **Excel:** Data staging and cleaning.
* **PostgreSQL & DBeaver:** Database schema setup, table creation, and SQL-based exploratory data analysis.
* **Power BI:** Data modeling, DAX measure creation, and interactive visual dashboard design.

## Key Features & Insights
* **Executive KPI Cards:** Track Total Employees, Employees Left, and Overall Attrition Rate in real time.
* **Department Breakdown:** Identifies which departments experience the highest turnover rates.
* **Overtime Analysis:** Highlights correlations between employee burnout (overtime) and departures.
* **Interactive Slicers:** Allows users to filter data dynamically by Department and Job Role.

## Files Included
* `employee_workforce_data.csv` - Raw staging data.
* `sql_analysis_queries.sql` - SQL queries used for data validation and extraction.
* `hr_workforce_dashboard.pbix` - Power BI interactive report file.
